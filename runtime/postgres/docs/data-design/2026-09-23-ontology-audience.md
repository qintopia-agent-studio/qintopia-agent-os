## 读取与决定

`Store::audience_preview(actor, collaboration)`
只对当前关系本人或有该关系联系管理委托者开放。每次检查会话、来源身份、任期、角色、职责、scope、原配置管理授权和 Gateway 范围。

返回必要姓名、Person 引用、当前/过往/待确认类别、是否符合选择及解释，不返回账户、订单或住宿原始 ID。

查询范围由当前关系及已登记的 tenant/scope → welcome
target/source 映射确定，不按楼栋显示名猜映射。PMS 来源身份必须已确认、有证据及确认人、关联本 tenant 的有效自然人；共享或未确认账号不作为自然人。社区可读其已授权后代楼栋；楼栋不能读其他栋名单。显式指定的人与动态人员去重。

当前判断要求最新投影无冲突、未失效、来源可用且非重建，观察时间在过去 60 秒到未来 5 秒内。当前有效安排及 active
occupant 优先归为在住；有本范围入住历史且可靠最新证据表明已离开才归为过往。资料过期、状态或身份无法确定显示待确认，不纳入动态选中名单。每个 Person 只出现一次。

`contact_decision`
对指定 Person 调用同一解析器，再应用主动联系/回复三态及现行发布权。预览结果不作为可重复使用的许可；实际执行仍需当次身份、对象、意愿、内容可见性及发送门禁。没有真实发送。

隔离数据库覆盖同住宿换栋、重复观察、历史回填边界、当前/过往/全部去重、跨栋/跨 tenant 拒绝，以及来源过期、冲突、失效、共享/未确认身份、原授权撤销、Gateway 越界和只读结果。
