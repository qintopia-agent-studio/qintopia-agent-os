# 舍长临时审批代理

在既有任职的 `designate` 与 `review`
有效自主权限下，舍长将本栋欢迎内容审核临时交给本栋当前在住且身份已核验的人。复用原任职作为授权来源，不授予组织管理、发布或其他业务权限。

新增 `collaboration_review_delegations`
保存每次指定的独立编号、tenant、scope、委托人、代理人、原指定／审核授权引用、有效区间与撤销时间。同一委托人在同一范围的安排以最新未撤销有效记录为准；更换时撤销原安排。命令使用共同持久回执，结果不明先查询。

名单和执行校验复用在住投影解析，来源过期、重建、冲突或退住不能授权。审批及发送准备均重验原授权和现行在住关系。批准依据绑定代理记录，替换或撤销后旧批准不能用于未发送内容。失效安排保留解释，不自动改为直接发送。

仅本地合成迁移；旧 checksum 不修改。测试指定权限与候选边界、幂等、到期、撤回、退住、跨栋、旧审批失效和上层发布确认独立性。回退关闭新入口，保留数据，使用兼容迁移的版本恢复。
