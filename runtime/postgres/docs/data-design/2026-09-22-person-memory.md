# 共同身份、本人回复偏好及住宿记忆

本批仅在隔离合成数据库验证，不初始化生产映射、权限或外部来源。

复用 `persons`、`source_identity_links` 和
`member_facts`。可信 Gateway 绑定保存 tenant、来源命名空间、标识类型、范围和账号类型；适配器只提供实际验证的来源主体，姓名不参与确认。共享工作账号不能取得自然人 Actor。

每次操作重新校验绑定、身份版本和状态。

来源观察只创建 pending 链接。QiWe `/contact/openid` 的 `userId/openUserId`
正向配对以受控适配证据保存在
`source_identity_links.adapter_metadata`，不自动确认自然人。员工标识和共享账号不能套用该转换。确认与撤销复用共同
`identity` 权力及管理范围、 `collaboration_commands`
幂等和版本，并调用欢迎已有的链接失效逻辑；旧关联与确认依据保留。

回复偏好由共同服务维护，模型只提出一般/费用条件下简短/详细或停止使用。本人来自 Actor，消息引用与观察时间来自可信适配器。聚合版本、消息幂等和观察时间共同防止并发覆盖、旧消息重放和停止后恢复。`member_facts`
保存独立有来源事实；当前使用状态独立保存，停止使用不删除必要审计，也不创建人工记忆工作事项。

当前读模型只返回本人服务所需的生效偏好。已有画像摘要在该人进入共同记忆权威后不再提供未经用途验证的整体摘要或旧沟通偏好；受控读取以共同事实版本为准。旧训练写法不能修改此权威。兴趣、技能、短期意愿和披露例外尚未接入，保持默认不披露。

住宿记忆复用已校验 PMS `welcome_source_versions` 的事务写入。增量触发器仅记录实际
`InHouse`
的稳定 source/property/stay/occupant，后续更新保留首次在住观察时间。换房和重复观察不新建住宿；再次入住的新 stay 保留独立历史。身份仍通过有效 PMS
occupant 关联解析。时间明确为来源观察时间，不伪装为缺失的实际抵达/离店时间。历史不因离店清除；当前状态需要最新、无冲突且未过期的 PMS 投影，未知不解释为离开。

本地读取以 24 小时作为来源新鲜度上限；这是保守的合成接入边界，真实来源时效仍须接入验证。不回填迁移之前没有保留的观察，也不将预订或取消伪装为已实际住宿。

长期成员关系只在存在可靠实际住宿记录后按 Person 保存，不授予任职或披露权限。

验证覆盖多 Gateway 同人、同名未知、共享账号拒绝、身份撤销、偏好跨会话读取、费用例外、停止/重放、并发旧版本、离店/再住、来源冲突与过期、无额外工作事项。

回滚停止新入口；保留追加事实、幂等记录和历史，不删除旧数据、不改变生产 worker。

最小已接线记忆类型为回复风格及费用条件例外。更广的兴趣、技能、短期意愿、人物介绍用途许可、年龄披露例外仍未接入；长期成员和住宿历史分别由 PMS 读模型证明，不将一个回复偏好样例称为完整人物记忆。

真实模型理解、QiWe 转换请求和账号范围尚待独立实测。
