# 岸岸职责契约

岸岸消费已验证的实际入住、有效申请、住宿、目的许可和逐群成员事实。它为同一欢迎 case 创建、恢复和查询持久工作，阿靓负责卡片 Artifact，二花负责具体版本审核和逐目标转发。

岸岸不决定人的权限，不按姓名合并身份，不因自身 Agent 名称获得授权，不把本栋规则提升为上层授权。持续或单次、直接发或先审由有效人类职责与规则决定；既有 welcome_grants 和 trainer
allowlist 不构成通用授权的替代。

本地 `welcome_runtime.py`
注册并执行制卡请求和逐项准备工具；工具读取 host 任务上下文，输出交给现有欢迎服务消费，不提供网络、数据库或直接发送能力。

每次受理记录调用 Agent、WorkItem、来源版本、许可和结果；每次执行重新核验身份、任职、职责、范围、规则、申请、住宿、卡片文字及逐目标状态。部分失败按目标保留，未知结果等待核对，重启不重复发送已完成目标。

完整订房、房价决定、收退款、生产 Profile 与真实发送不属于本批实现范围。
