## 交付行为

- 舍长主要入口为四个顶部标签：与二花对话、本栋知识、合作约定、事项与进展。管理员原组织页保留，普通账号只能操作本栋；欢迎不是独立导航。
- 本栋知识可导入 UTF-8 Markdown（12
  KB）、修改、定时生效／结束、停止和重新启用。历史可搜索、筛选与翻页，单条查看前后版本。知识操作使用独立知识权限，旧入口也不能以修改约定权绕过。
- 舍长按已有授权设置欢迎“仅本次／持续”“先审／卡片文案直发”和期限。直发设置不重复要求本人审批，但保留上层确认、实际入住、群成员与内容使用许可条件。
- 舍长从系统核验的本栋当前在住名单中搜索选择临时内容审批代理，必须有截止时间，可更换或撤销。代理没有组织管理、欢迎配置或推进发送权限；审批和发送重新核验原授权、身份、在住与期限，旧代理批准失效。
- Web 与新增 Hermes 可信工具共用服务、版本和持久回执；页面展示仍区分本地测试结果与真实送达。没有新增模型供应商或生产 Profile。

## 使用与验收

本地地址 `http://127.0.0.1:18877/`。使用原合成账号 `house-one` 或
`house-two`，密码沿用原本地配置。实例保留数据，不重新初始化。两个样例账号的知识维护、指定审核人权限通过管理员正常预览／保存补充，其他已有授权不变。

1. “本栋知识”新增或导入 MD，保存后在对话查询当前内容；修改、设截止或停止，再查结果。
2. “合作约定”维护本栋文本约定；入住欢迎选择本次或持续、先审或直发，保存不会立即发送。
3. 指定当前在住代理并设置截止，在代理的事项页面批准具体卡片和文案；撤销后旧批准不再授权未发送内容。
4. “事项与进展”查看卡片、正文、等待原因和执行结果。实际推进仍是明确标注的本地发送测试。
