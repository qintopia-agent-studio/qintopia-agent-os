# 壁炉区报警工作流审阅记录

原有涂鸦订阅已收到壁炉区报警器的按键自检。自检成功、无故障，烟雾和一氧化碳分别上报正常。共享查询程序已经按现行版本核对。此次将查询能力和报警工作流纳入同一仓库审阅，生产环境沿用原接收服务。

## 验证范围

用模拟设备、临时 SQLite 和群发送回执验证自检静默、两项报警、每群三次上限、恢复取消，以及重启时的去重。原始密钥、群地址和设备 ID 保存在主机。本次未触发设备或向群发送测试消息。

回归测试分别检查四老师和二花的投递记录。烟雾持续、另一项短暂报警又恢复时，两群各在首条后第 30 秒和第 60 秒收到模拟烟雾提醒。两个群收到不同轮次的撤离通知时，按各自成功回执补一次最终恢复。延迟补查保留同一秒内的先后顺序，任一项仍有更新的云端报警时暂停恢复通知。

模拟发送器的启动失败、超时和回执不明分别验收。只有明确未启动时会按原序号重试。重启测试沿用原来的生效时间、已占用序号和群回执。

## 发布归属待审

仓库现有规则已将 MCP 适配器纳入系统服务，并分别覆盖四老师与二花的 profile。重启范围预检会报告共享 Skill 的清单和报警工作流代码尚无归属。复核该 PR 时可在仓库根目录运行：

```sh
node tools/deploy/resolve-restart-targets.mjs --base-ref origin/master --head-ref HEAD
```
