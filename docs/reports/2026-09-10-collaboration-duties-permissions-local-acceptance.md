# 秦托邦协作框架：职责与权限本地交付

本轮承接用户“你实现吧”的授权，落实通用框架的对象维护、完整工作连接与权限判断。不限定一栋或入住欢迎。一栋投喂包只是需求适配案例，没有作为岗位和权限的唯一来源。

本次交付是可持久保存的本地配置能力；真实智能体尚未按这些设置工作。完整框架的合作启动、知识确认和真实执行入口仍需后续接入，不能称为生产上线或完整框架验收完成。

## 已完成

| 使用者要做的事         | 本地实现                                                                             |
| ---------------------- | ------------------------------------------------------------------------------------ |
| 看懂人与智能体如何配合 | 秦托邦顶层；总览逐行呈现人、岗位、职责、智能体、工作范围，支持筛选与点击查看         |
| 维护岗位与职责         | 六个独立入口；岗位关联可复用职责，均可新增、编辑和移除；有历史的对象停用保留         |
| 明确授权边界           | 每项权限明确为可自主决定、需指定人员确认或未授予，附解释、例子与边界                 |
| 给舍长安排居民服务     | 从岗位关联职责选择适用权限，不出现技术支持；岗位名称不自动授予权限                   |
| 调整或交接一条工作     | 可更换人、岗位、职责、智能体、范围；同事务结束原连接并创建替代连接，保留历史         |
| 结束一项合作           | 仅结束这条连接；最后一条连接结束时关闭空任职，其他工作继续保留                       |
| 检查权限是否成立       | 绑定完整连接的检查接口返回自主、需要确认或拒绝，不产生业务批准或外部调用             |
| 防止配置意外扩大授权   | 方案新增权限不改变旧授权；缩减在用职责、移除当前引用会拒绝；管理链失效后拒绝执行判断 |

确认人必须是其他已核验自然人，在同职责、智能体、领域和范围内拥有该项自主决定权。每次判断重新核对授权链、身份、任职和有效期；确认人到期或撤权不能变成自主放行。需要确认的管理权限不能调用自主管理入口。

职责和补充说明可输入多行自然语言；权限本身使用明确选项，不把说明文字变成隐含授权。普通提供信息不需要岗位授权。开放接待、主动联系和信息可见性沿用此前约定，实际入口未启用。

## 浏览器实际操作

在 `http://127.0.0.1:18871/` 验证：

1. 舍长自动匹配居民服务，权限默认未授予，建立连接的权限列表没有技术支持。
2. 新建自主关系、多行说明、预览及保存；刷新和进程重启后仍能读取。
3. 无资格确认人被拒绝；改选有权人员可保存，权限检查显示需要该人确认。
4. 未授予的主动发消息权限拒绝；撤销确认人权限后，依赖关系显示当前不可决定。
5. 对本次新建的临时岗位、职责、范围分别新增、编辑、更名和删除，保存结果可读回。
6. 仅替换本次新建连接的楼栋，旧连接显示已结束；结束新连接后，另一人的有效连接仍在。
7. 旧无职责连接标记待关联，不展示为已生效自主权限；权限检查只列当前职责及自身历史权限。
8. 桌面 CSS 宽度 1600、窄屏实际 CSS 宽度 487 的总览与权限表单均无横向页面溢出。窄屏请求尺寸为 390
   × 844，应用缩放后的实际 CSS 宽度为 487；未把它记成真实 390 CSS 像素测试。

临时目录对象验证后删除。保留本地人员乙／一栋、人员丙／二栋的居民服务连接及验收历史，方便继续查看。这些都是隔离样例，不能视为真实任命或待投产授权。

自动审批检查拒绝了编辑预置“小管家”及移除预置岗位的浏览器调用，理由是把用户此前“不能编辑”的问题描述视为禁止修改。该调用未执行；本轮未绕过拒绝去写这些预置岗位。之后改用本次新建临时对象验证相同维护路径。岗位维护代码对预置与新增对象共用，不把替代验证描述成已实际修改预置岗位。
