# 本栋约定生命周期修复与本地交接

本次补齐用户审阅指出的六个缺口：整项无法停止、指定确认无可操作待办、查询不显示正文、无截止日期、未来安排无法修改取消、固定厨房对话丢失名称与截止时间。沿用已有组织页面和舍长“我的工作”，不添加欢迎导航。基于
`b195194`，分支 `codex/person-rule-lifecycle`。

## 已实现行为

- 当前约定可新增、修改、设起止日期；停止整项会同时取消未来安排，历史可展开查看。重新启用必须明确操作。
- 未来安排可以修改和取消。截止后不自动恢复旧版；结构化欢迎的原专用语义保持兼容。
- 需指定人确认的请求显示正文、起止时间和提交时原内容；确认人批准并执行或拒绝，请求人可撤销，刷新后可继续查看结果。停止后的旧请求执行会因版本冲突失败。
- 舍长只使用本栋业务授权。兼任管理者的确认人在组织岗位详情进入本范围约定与审批；管理身份本身不能替代业务权限。
- 本地对话查询返回实际约定正文；明确命名的增改停使用同一服务。仅改正文保留名称和截止时间。歧义不猜测，任意自然语言与真实模型仍不在此次通过范围。
- 未取得写回执时保留草稿，先读取状态，再允许以原编号、原内容核对或重试，不自动产生第二次写入。

真实浏览器换账号验收额外发现并修复：舍长退出登录会使持久请求执行失败、舍长受限人员列表无法显示确认人的名字。现在退出或会话自然到期不会撤销已提交请求；账号停用、密码重置、身份或授权变化仍会阻断旧请求。确认人名称由当前授权服务返回，不扩大组织人员可见范围。
