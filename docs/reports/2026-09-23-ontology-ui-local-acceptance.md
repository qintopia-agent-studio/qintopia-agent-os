## 受众与页面边界

组织管理者使用原有“组织关系 / 配置任职与范围 / 基础台账”。舍长在日常对话中通过二花办理事项。欢迎仍是已有授权内的具体事项，没有独立导航、业务分类或配置台。
`/foundation` 仅供隔离本地对话验收，不进入产品导航。

复杂操作旁增加说明图标，支持鼠标悬浮、键盘聚焦、点按和 Esc。任职、换任及撤权影响直接显示在预览中。保留原深色主题、组织层级与三态授权；详情逐层展开，用户不需要输入数据库 UUID。

## 实现与约束

| 使用者需要判断的事     | 页面与服务实现                                                                                 |
| ---------------------- | ---------------------------------------------------------------------------------------------- |
| 谁负责、何时开始       | 任职支持未来开始与明确截止；尚未开始明确显示没有可执行权限，更新时保留原开始时间               |
| 工作受什么约束         | 岗位详情引用当前适用的已确认规则、来源、确认人、版本、范围及有效期，包含共享上层约束           |
| 账号是否属于本人       | 人员详情列出可信来源已有候选，预览核对后确认或撤销；共享账号、未观测来源及命名空间冲突拒绝关联 |
| 撤销会影响什么         | 展示会话、任职和委派影响；最后核验撤销后旧权限失效，重新核验不恢复旧权                         |
| 智能体现在能否执行     | 分开显示登记、当前范围配置、本地执行器与真实渠道；合成本地能力不冒充真实模型上线               |
| 实际覆盖哪些人         | 同一服务解析本范围当前、过往、明确选择与待确认人员；去重并在执行前重新核验                     |
| 谁修改了什么           | 变更记录展示操作者、时间、前后内容及影响；旧记录缺失的信息明确标注                             |
| 启用账号为何仍不能登录 | 只读显示当前身份与人员状态的登录限制，重置密码不解除身份限制                                   |

身份写入复用密码会话、身份管理权、配置/来源/Gateway 三重版本校验和幂等回执。浏览器不能提供操作者、命名空间或核验证据。旧欢迎身份入口同时失效已派生的组织身份投影，避免残留权限。

动态名单只接纳可信范围内的实际入住依据；过期、冲突、空楼栋、未确认及共享身份保持未知，不归入过往住客。006 保存按楼栋的实际入住观测历史；旧记录仅回填已记录的最后楼栋。007 追加幂等安装与 schema 登记，保留已应用 006 的 checksum。迁移与恢复详见[数据设计](../../runtime/postgres/docs/data-design/2026-09-23-ontology-audience.md)。

## 浏览器实测（2026-09-23）

在原 Codex 浏览器及现有 v4 合成 tenant 操作，没有清空第一批数据：

- 三项原导航与组织层级保持。岗位详情显示共同文化和本栋当前厨房规则，展开可见来源、记录人、版本与有效时间；没有欢迎分类。
- 人员“界面验收人员 · 合成”经登记进入待核验；明确选择合成来源账号、预览影响并确认后进入在册，仍没有任职。撤销再次预览后回到待核验，刷新保留来源与历史。
- 一栋保存“当前在住人员”范围后，实际名单显示 1 位合成住客；回复与主动联系仍为未授予，未发生发送。
- 三栋保存 9 月 30 日开始的未来任职；错误截止先被人话提示拒绝。将截止由 10 月 1 日改为 10 月 2 日后，开始时间不变，页面仍显示“尚未开始”。
- 历史记录显示操作者、身份核验对象和账号。仅修改截止时间的记录只显示截止变化，不把权限排序变化当成改权。
- 二花能力详情显示明确查看范围、登记、已保存安排、本地可验收与真实渠道尚未启用。账号页面区分启用状态和当前登录条件。
- 切换 `house-two`
  后仅显示二栋任职，配置操作不可用；身份管理明确说明无权，完整历史不展示。最终恢复
  `admin` 和原组织页面。
- 说明图标实测键盘聚焦、点按、Esc 关闭；窄屏触点约 44 CSS
  px。390×844 视口覆盖在当前浏览器缩放下对应 469 CSS
  px 内容区，页面无横向溢出，浮层四边至少留 12 px，日期控件可操作；测试后恢复原视口。

鼠标悬浮已由 `pointerenter` / `pointerleave`
实现；本轮浏览器工具未单独模拟“只移动鼠标而不点击”，此手感留待人工验收。修复后没有新增浏览器控制台错误，保留首次错误证据。
