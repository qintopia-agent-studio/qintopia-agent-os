## 总指挥的全局核对职责（2026-09-22 再次明确）

负责人要求总指挥持续掌握跨系统脉络、数据归属、连接和历史决定；不能只围绕当前欢迎工作理解整个项目。每次跨领域判断先定位权威来源、相关 Agent、上下游、已有决定、实际版本和未完工作。未核实的部分明确留作待查，不用印象补齐或让负责人重复已经记录的决定。
