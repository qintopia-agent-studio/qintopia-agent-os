# 小满工作流现状报告

日期：2026-07-30

## 脱敏验证边界

本报告只保留工作流能力和缺口，不记录 live 服务器状态。生产 release 指向、Hermes profile
env、systemd/timer 状态、生产 env 文件权限和 gateway 运行态必须留在外部运行证据或 runbook 输出中，不复制进 git。

需要通过外部证据确认的事项：

- release-local sidecar 与 Hermes profile 指向同一个已发布 release。
- sidecar 环境文件权限满足 Hermes/MCP 读取边界，且不暴露 secret。
- 小满和二花 gateway 运行正常，相关 MCP 子进程可启动。
- 历史遗留任务已按 runbook 停用，且不会与 AgentOS worker 重复触发。
- 一次脱敏的 `next_day_preview` 样例已通过人工审核前的文案生成路径。

## 目标架构

目标架构是：飞书多维表格作为活动与图片的事实源，小满读取后生成文字预告与提醒，经运营确认后由二花发群；海报 brief 由阿亮/IMG
2 生成图片存入飞书，确认后进入发群链路；活动结束后触发素材回填提醒，连续三次未回填则标记遗漏。

## 当前已完成的流程

已完成：小满可读取飞书 Base 活动记录并生成文字预告；图片生成 preflight 和 worker 状态需要通过外部 release-local 证据确认；飞书图片表状态不在 git 中保留 live 快照。未完成：二花企微发群未激活，海报端到端未闭环，素材回填提醒尚未形成多轮催办闭环。

## 未完成的卡点

1. 二花发群未激活：QiWe image-send 需 owner 决策和 release-local evidence。
2. 端到端未验证：从“活动录入 -> 小满生成预告 -> 运营确认 -> 二花发群 -> 企微到达”尚未跑一次真实流程。
3. 海报生成链路未闭环：preflight 通过，但缺少真实 brief 到生成到确认到发送的完整测试。
4. 素材回填提醒未实现：活动结束后自动提醒运营回填、连续三次未回填标记遗漏的逻辑未上线。
5. 飞书镜像激活状态不进入 git：需 owner 按 guarded 流程执行并保留外部证据。

2. 若文字 MVP 通过，再决策是否激活 QiWe image-send 进行图片端到端测试。
3. 按 guarded 流程激活 Feishu mirror worker，并把观察 smoke 输出保存在外部证据中。
