# 协作设置界面纠偏

依据：用户关于分类标签、协作图、岗位适用职责、页面分区和权限解释的反馈。产品依据是本任务已确认的共同沟通与界面讨论稿；一栋投喂包仅用于验证框架能否承接具体需求。

## 本次改动

- 协作总览呈现已保存的人员／岗位、智能体、范围与群的关系图，可按范围、智能体和职责筛选。
- 建立合作、岗位与职责、工作范围分为独立页面；人员与智能体视角使用同一份关系数据。
- 每项职责展示业务名称、解释、例子与边界。人人提供信息不作为待授予的权限。
- 岗位保存可选职责清单，任职时再逐项授权，不因岗位名称自动授权。舍长的合成岗位方案不包含技术支持；一人兼做技术支持时另建技术岗位合作。
- 新岗位可由管理者选择适用职责；服务端拒绝超出岗位清单的合作设置。这是一组可维护的职责类别，不枚举厨房、书架等所有生活事项。
- 保留本地预览、持久保存、撤权和任职结束；不把尚未接入的知识、合作引导或发送展示成已启用。

## 界面取舍与验证

沿用浅底、深绿主色、系统中文字体，8px 间距基准；主导航与任务页分开，关系图使用清楚的节点和连线。不新增外部资源、图形依赖或生产数据。宽屏优先展示网络，窄屏将每条关系纵向排列。

验证：岗位越界的服务端测试；浏览器核对分区、筛选、岗位切换、职责解释、预览保存与窄屏溢出。上一版 F1 的本地技术测试不代表通过用户界面验收。本次仍需用户实际查看纠偏后的界面。
