- 暂停合并、发布部署、生产配置与数据库变更、真实投递和旧飞书流程切换；不改服务器或 Hermes
  profile。

- 仅使用虚构人员、群和业务对象，执行器保持测试替身或禁止外部副作用。不导出真实人员、聊天、群标识、凭证或生产日志。
- 先确认测试数据库、tenant、端口和进程归属；不得重置其他任务的环境。历史通过的测试优先引用，只为新变化、证据缺口或相关失败补跑。

可以补测试，但应服务于尚未证明的业务行为。当前先核对覆盖；不为增加测试数量重写已有测试，不把尚未实现的 C/D 用纯 mock 包装成已通过。

### 运行时可以替换：负责人补充的架构目标

负责人说明：此前另一位同事把部分应属于 Agent
OS 的功能放进 Hermes，影响 Hermes 大版本升级。当前架构同事正剥离这些功能并迁回 Agent
OS。这是负责人提供的背景，尚未通过源码和运行检查核实剥离范围与完成情况。

目标是让 Hermes 或其他运行时通过适配层执行工作，升级或替换运行时不要求重写人员、授权和业务流程。该目标不代表更换运行时无需适配或验收，也不表示本轮决定改用 OpenClaw 或恢复任何旧集成。

| 所属层         | 应承担的责任                                                                                                | 接入约束                                                                                                |
| -------------- | ----------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| Agent OS       | 稳定人员身份与跨渠道关联、组织岗位与授权、业务关联与安全背景、Event Inbox、WorkItem、审核、幂等、审计与恢复 | 业务事实与持久协作状态不以 Hermes profile、会话或私有表为唯一来源；PMS 仍是住宿事实源                   |
| 运行时         | 模型推理、执行会话、工具调用以及该次执行的临时上下文                                                        | 不能用 prompt 或本地记忆授予业务权限；执行前由受控工具/服务校验当前身份和范围                           |
| 运行时适配层   | 受控领取或调用、执行上下文传递、任务状态/产物/回执归一、超时与取消对接                                      | 保留真实发起人、委托与审计关联；运行时会话/任务编号只是外部引用，不替代 person_id、WorkItem 或事件标识  |
| 外部系统接收层 | PMS/飞书/渠道事件的认证、标准化、持久接收及补偿                                                             | 事件先进入 Agent OS 受控 Inbox；运行时不可用时事件和待办仍保留，不把接收地址绑定到某个 Agent 的聊天入口 |

当前两项准备增加一个检查维度：哪些接口、业务状态或流程直接依赖 Hermes 的内部 prompt、profile 路径、会话或数据库，哪些应交给架构剥离工作处理。只列依赖与归属，不在本轮自行迁移，不与架构同事重复建设调度、身份、授权或接收服务。

未来运行时替换的验收至少包括：Agent
OS 脱离 Hermes 仍能保存和查询人员/授权/事件/任务；升级或切换后稳定标识及历史保留；旧执行者失效后不能重复领取或发送；在途任务和未知发送结果可查询、接管与恢复；新运行时受相同的楼栋和动作权限约束。

以上先用独立服务测试和合成适配器检查边界。替代运行时的实际兼容性仍需其真实适配器验收，不能用测试替身通过宣称可以直接切换。
