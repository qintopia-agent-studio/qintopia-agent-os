# Claude Code Instructions

Follow [AGENTS.md](AGENTS.md) as the primary operating contract. This file is only an
entrypoint; it does not maintain a separate policy or grant additional authority.

## Start Here

1. Read [README.md](README.md) and [AGENTS.md](AGENTS.md).
2. Read the [documentation hub](docs/README.md),
   [architecture](docs/architecture/agent-os-overview.md),
   [roadmap](docs/plans/active/current-roadmap.md),
   [programming guardrails](docs/engineering/programming-agent-guardrails.md) and
   [change routing](docs/engineering/change-routing-index.md).
3. Identify affected packages, read their README/manifest and applicable directory
   AGENTS.md files. Sibling rules are not inherited automatically.
4. Follow the root task entry for product/design/runtime context and migration evidence,
   and read the full topic contracts relevant to the proposed change.
5. Use the root completion criteria for checks, PR body and reporting.
